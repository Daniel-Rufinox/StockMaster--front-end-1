# StockMaster — Sistema de Controle de Estoque Comercial

Projeto front-end desenvolvido para o trabalho de curso.

## Tecnologias front-end definidas

- **HTML5** — estrutura semântica das páginas
- **CSS3** — folha de estilos própria, variáveis CSS, Flexbox, Grid e layout responsivo
- **JavaScript (ES5/vanilla)** — regras de negócio, validações e persistência via `localStorage`

Sem frameworks e sem build: basta abrir os arquivos no navegador.
